Configures a provider for Machine-to-Machine (M2M) authentication using the OAuth 2.0 
`client_credentials` grant type. 

This provider does not have a UI and is intended for service-to-service communication where 
the client can securely store a secret.

```ts
import { M2MProvider } from "@_mustachio/openauth/provider/m2m"

export default issuer({
  providers: {
    m2m: M2MProvider({
      verify: async (clientID, clientSecret) => {
        // Verify against your database
        const client = await db.clients.findUnique({ where: { clientID } })
        if (client && client.secret === clientSecret) return client
      }
    })
  },
  success: async (ctx, value) => {
    if (value.provider === "m2m") {
      return ctx.subject("org", {
        orgID: value.orgID
      })
    }
  }
})
```

To request a token, the machine makes a POST request to the `/token` endpoint.

```bash
curl -X POST https://your-auth-server.com/token \
  -d "grant_type=client_credentials" \
  -d "provider=m2m" \
  -d "client_id=YOUR_CLIENT_ID" \
  -d "client_secret=YOUR_CLIENT_SECRET"
```

The callback to verify the client credentials. 

Takes the `clientID`, `clientSecret`, and any additional parameters passed in the request.

Should return an object containing information about the client (e.g., associated User or Org ID). This object will be available in the `success` callback.

Returning `undefined` or throwing an error indicates invalid credentials.
